# Stellar Burgers — UI Testing

## О проекте

Stellar Burgers — веб-приложение для заказа бургеров. В рамках проекта проведено функциональное тестирование пользовательского интерфейса с использованием автоматизированных UI-тестов.

## Что тестировалось

* переход между разделами конструктора бургеров;
* выбор ингредиентов;
* работа с конструктором бургера;
* регистрация и авторизация пользователя;
* оформление заказа;
* отображение данных пользователя;
* выход из аккаунта;
* переходы между страницами и разделами приложения.

Тесты проверяют основные пользовательские сценарии и корректность работы интерфейса.

## Инструменты

* Python
* Pytest
* Selenium
* Allure

## Структура проекта

* `tests/` — автоматизированные UI-тесты;
* `conftest.py` — фикстуры для тестов;
* `requirements.txt` — зависимости проекта.

## Запуск тестов

```bash
pytest
```

Для формирования Allure-отчёта:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```
# Stellar Burgers — API Testing

## О проекте

Stellar Burgers — веб-приложение для заказа бургеров. В рамках проекта проведено тестирование REST API приложения.

## Что тестировалось

### Создание пользователя

Проверены сценарии:

* успешное создание уникального пользователя;
* создание пользователя, который уже зарегистрирован;
* создание пользователя без обязательного поля.

### Авторизация пользователя

Проверены сценарии:

* успешная авторизация зарегистрированного пользователя;
* авторизация с некорректными данными;
* работа API при отсутствии необходимых данных.

### Создание заказа

Проверены сценарии:

* создание заказа авторизованным пользователем;
* создание заказа без авторизации;
* создание заказа с ингредиентами;
* создание заказа без ингредиентов;
* создание заказа с некорректным хешем ингредиента.

## Исследуемые данные

В тестах использовались данные пользователей, токены авторизации и идентификаторы ингредиентов, получаемые через API.

## Инструменты

* Python
* Pytest
* Requests
* Allure

## Структура проекта

* `tests/` — API-тесты;
* `conftest.py` — фикстуры;
* `helpers/` — вспомогательные функции для работы с API;
* `requirements.txt` — зависимости проекта.

## Запуск тестов

```bash
pytest
```

Для формирования Allure-отчёта:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```
