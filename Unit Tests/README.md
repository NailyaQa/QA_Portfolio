# тестирование класса BooksCollector

## Проверяемые методы

### add_new_book
Проверки:
- успешное добавление двух книг;
- книга с названием длиннее 40 символов не добавляется;
- у новой книги жанр пустой.

### set_book_genre
Проверки:
- корректная установка жанра книге;
- использована параметризация для разных жанров.

### get_book_genre
Проверки:
- получение жанра книги по названию.

### get_books_with_specific_genre
Проверки:
- получение списка книг определённого жанра.

### get_books_genre
Проверки:
- получение словаря `books_genre`.

### get_books_for_children
Проверки:
- книги с возрастным рейтингом не попадают в список детских книг;
- книги без возрастного рейтинга отображаются в списке.

### add_book_in_favorites
Проверки:
- добавление книги в избранное.

### delete_book_from_favorites
Проверки:
- удаление книги из избранного.

### get_list_of_favorites_books
Проверки:
- получение списка избранных книг.
